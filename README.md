K-mer Distribution Project
This project computes the k-mer distribution of DNA sequences using two different data structures:
Hash Tables (HT) — two separate implementations using different hashing functions
Binary Search Tree (BST) — implemented fully from scratch (excluding BST libraries)
The goal is to compare the performance, collision frequency, and behavior of these approaches for various DNA sequence lengths and k-mer sizes.
